React Demo Documentation

A comprehensive guide to creating React applications with a single codebase for multiple platforms

Introduction

React is a JavaScript library for building user interfaces that allows developers to create large web applications that can update without reloading the page. React Native extends this capability to mobile app development, enabling you to build native apps for Android and iOS using the same codebase.

This documentation provides an overview of how to use React and React Native with a shared Git repository to develop applications that work across web, iOS, and Android platforms.

Architecture Overview

A typical React/React Native multi-platform architecture involves:

React Native Architecture with shared codebase for multiple platforms

  • Shared Codebase: Business logic, state management, and UI components that work across platforms
  • Platform-Specific Code: Code that needs custom implementations for each platform
  • Native Bridges: Communication layers between JavaScript and native platform code

Getting Started

To create a new React Native project with web support:

// Install the React Native CLI
npm install -g react-native-cli

// Create a new React Native project
npx react-native init MyAwesomeApp

// Add web support
cd MyAwesomeApp
npm install --save react-dom react-native-web
npm install --save-dev @babel/core babel-plugin-module-resolver

Project structure:

MyAwesomeApp/
├── android/            # Android-specific code
├── ios/                # iOS-specific code
├── src/
│   ├── components/     # Shared UI components
│   ├── screens/        # Screen components
│   │   ├── Home.js     # Shared home screen
│   │   ├── Home.ios.js # iOS-specific override
│   │   └── Home.web.js # Web-specific override
│   └── services/       # Business logic, API calls
├── web/                # Web-specific entry point
├── App.js              # Main app component
└── index.js            # Entry point

Code Sharing Strategy

Here are some strategies for sharing code across platforms:

1. Platform-Specific File Extensions

React Native automatically picks the right file based on platform:

// Button.js - Default implementation
// Button.ios.js - iOS-specific implementation
// Button.android.js - Android-specific implementation
// Button.web.js - Web-specific implementation

2. Platform Module

Use the Platform module for conditional code:

import { Platform } from 'react-native';

const styles = StyleSheet.create({
  container: {
    flex: 1,
    ...Platform.select({
      ios: {
        backgroundColor: 'red',
      },
      android: {
        backgroundColor: 'blue',
      },
      web: {
        backgroundColor: 'green',
      },
      default: {
        backgroundColor: 'gray',
      },
    }),
  },
});

3. Higher-Order Components

Wrap components with platform-specific behavior:

// withPlatformSpecificBehavior.js
const withPlatformSpecificBehavior = (Component) => {
  return props => {
    // Add platform-specific behavior here
    return ;
  };
};

export default withPlatformSpecificBehavior;

Git Repository Management

Best practices for managing your shared repository:

  • Branch Strategy: Use main for stable code, feature branches for development, and platform-specific branches when needed.
  • Monorepo Structure: Consider using a monorepo tool like Lerna or Yarn Workspaces for more complex applications.
  • CI/CD Setup: Configure separate build pipelines for each platform but trigger them from the same code changes.

Common Challenges

Navigation

Navigation patterns differ between web and mobile. Consider using React Navigation with web extensions.

Styling

Styling approaches vary. Use a library like styled-components that works well across platforms.

Native Features

Some features require platform-specific implementations. Use a consistent abstraction layer for camera, geolocation, etc.

Example Component

Here's a simple cross-platform button component:

// CrossPlatformButton.js
import React from 'react';
import { TouchableOpacity, Text, StyleSheet, Platform } from 'react-native';

const CrossPlatformButton = ({ title, onPress }) => {
  return (
    
      {title}
    
  );
};

const styles = StyleSheet.create({
  button: {
    backgroundColor: '#4F46E5',
    padding: 15,
    borderRadius: 5,
    alignItems: 'center',
    ...Platform.select({
      web: {
        cursor: 'pointer',
        outline: 'none',
        transition: 'background-color 0.3s',
      },
      ios: {
        shadowColor: '#000',
        shadowOffset: { width: 0, height: 2 },
        shadowOpacity: 0.1,
        shadowRadius: 2,
      },
      android: {
        elevation: 2,
      },
    }),
  },
  text: {
    color: 'white',
    fontWeight: 'bold',
    fontSize: 16,
  },
});

export default CrossPlatformButton;
