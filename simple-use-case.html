LLM Interaction Points

LLM Call #1: Intent & Entity Extraction

The first LLM call analyzes the query to determine intent and extract entities.

Example Prompt:
You are an AI assistant that analyzes user queries to identify the intent and extract entities. USER QUERY: "Find me red Nike shoes under $100" Extract the following information: 1. Main intent of the query (e.g., product_search, order_tracking, customer_service) 2. All relevant entities in the query (product types, attributes, constraints, etc.) Format your response as a JSON object with the following structure: { "intent": string, "confidence": number between 0 and 1, "entities": { entity_name: entity_value } }
Example LLM Response:
{ "intent": "product_search", "confidence": 0.98, "entities": { "product_type": "shoes", "brand": "Nike", "color": "red", "price_max": 100 } }

LLM Call #2: API Plan Generation

The second LLM call creates an execution plan based on available APIs and extracted information.

Example Prompt:
You are an AI assistant that creates API execution plans based on user intent and available API endpoints. USER INTENT AND ENTITIES: { "intent": "product_search", "entities": { "product_type": "shoes", "brand": "Nike", "color": "red", "price_max": 100 } } AVAILABLE API ENDPOINTS: 1. GET /products/search - General product search with filtering Parameters: category, brand, color, price_min, price_max, page, page_size 2. GET /products/{id} - Get details for a specific product Parameters: id 3. GET /brands/{brand}/products - Get products from a specific brand Parameters: brand, category, page, page_size 4. GET /shipping/options - Get shipping options for products Parameters: product_ids, location Create an execution plan that efficiently fulfills the user's request. The plan should: 1. Use the most appropriate APIs 2. Include all necessary parameters 3. Define dependencies between API calls if needed 4. Include fallback options in case of errors Format your response as a JSON object with the following structure: { "api_calls": [ { "endpoint": string, "method": string, "parameters": object, "depends_on": string or null, "expected_response": string } ], "fallbacks": [ { "if_failed": string, "then_use": object } ], "success_criteria": { "condition": string } }
Example LLM Response:
{ "api_calls": [ { "endpoint": "/products/search", "method": "GET", "parameters": { "category": "shoes", "brand": "Nike", "color": "red", "price_max": 100, "page": 1, "page_size": 20 }, "depends_on": null, "expected_response": "product_array" } ], "fallbacks": [ { "if_failed": "api_call_0", "then_use": { "endpoint": "/brands/Nike/products", "method": "GET", "parameters": { "category": "shoes", "page": 1, "page_size": 20 } } } ], "success_criteria": { "condition": "$.api_call_0.response.products.length > 0" } }

Simplified Planner Flow

1

Preprocessing

The user query is normalized and cleaned up. Context from previous interactions may be added.

Input:

"Find me red Nike shoes under $100"

Output:

"red Nike shoes under $100"

2

LLM Planning

The LLM analyzes the query, extracts intent and entities, and creates an execution plan.

Key Actions:

  • Identify intent: product_search
  • Extract entities: product_type, brand, etc.
  • Match with available APIs
  • Create structured execution plan
3

Execution

The Executor Agent receives the plan and makes the necessary API calls in sequence.

Actions:

  • Call /products/search API
  • Process API response
  • Use fallbacks if needed
  • Format data for Generator Agent

Key Benefits of This Approach

Simplified Architecture

  • Just two main LLM calls instead of multiple specialized components
  • Clearer flow that's easier to implement and debug
  • Reduces latency by minimizing the number of processing steps
  • More cost-effective with fewer LLM calls

Powerful LLM Prompting

  • Leverages LLM's inherent understanding of language and intent
  • Clear, structured prompts ensure consistent outputs
  • JSON formatting makes integration with other components seamless
  • System can improve by refining prompts rather than rewriting code
