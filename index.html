A Beginner's Guide to HTML with Examples

Welcome to HTML Learning

HTML (HyperText Markup Language) is the standard markup language for creating web pages. It describes the structure of web pages using markup elements that are represented by tags.

This guide will help you learn HTML basics through examples and practice.

Tip: The best way to learn HTML is by practicing and building your own web pages.

HTML Basics

HTML Document Structure

Every HTML document follows a basic structure:

<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Page Title</title>
</head>
<body>
<!-- Content goes here -->
<h1>Hello World!</h1>
<p>This is a paragraph.</p>
</body>
</html>

HTML Elements

HTML elements are represented by tags. Tags contain content and other tags.

Element Description
<h1> to <h6> Heading elements (h1 is the largest, h6 is the smallest)
<p> Paragraph element
<a> Anchor element (for links)
<img> Image element
<div> Division element (container for other elements)
<span> Inline container for text
<ul>, <ol>, <li> List elements (unordered list, ordered list, list item)

HTML Forms

Forms are used to collect user input. Here's a simple contact form example:

<form>
<div>
<label for="name">Name:</label>
<input type="text" id="name" name="name">
</div>
<div>
<label for="email">Email:</label>
<input type="email" id="email" name="email">
</div>
<div>
<label for="message">Message:</label>
<textarea id="message" name="message" rows="4"></textarea>
</div>
<button type="submit">Submit</button>
</form>
Important: Always validate user input both on the client side (with HTML5 validation attributes) and on the server side.
